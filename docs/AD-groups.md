<h1>How and Why AD Groups Are Important</h1>

<p>Active Directory (AD) groups are one of the core components that make a Windows-based network functional and efficient in a work environment.</p>

<hr>

<h2>What are AD groups?</h2>

<p>Within Active Directory, each user is assigned to a number of groups. These groups define what the user has access to across systems and services.</p>

<p>As a standard, users are typically assigned to groups that provide access to Microsoft 365 services, such as Outlook, Teams, and other essential tools.</p>

<hr>

<h2>What AD groups control</h2>

<p>AD groups are used to manage access and permissions across multiple systems:</p>

<p>- Application access via SCCM (e.g., assigning software like Google Chrome)</p>
<p>- Access to network drives and shared folders</p>
<p>- Permissions based on departments (e.g., Marketing, HR, IT)</p>

<p>For example, if a user needs access to Google Chrome, a group can be created or used that deploys Chrome via SCCM. Once the user is added to that group, they will gain access to the application.</p>

<p>Similarly, access to network drives is controlled through groups, where specific folders are assigned to specific departments or roles.</p>

<hr>

<h2>Access control and approval</h2>

<p>In most cases, access to AD groups requires approval from the user's manager before changes can be made.</p>

<p>This ensures that permissions are granted correctly and that there is clear authorization for access changes. It also helps maintain security and proper governance within the organization.</p>

<p>For me, this makes it clear what access I am allowed to grant and what requires further approval.</p>

<hr>

<h2>Practical example</h2>

<p>If a user needs access to software such as Adobe Creative Cloud, this can be handled by adding the user to the appropriate AD group that controls access to that application.</p>

<p>Once added, the system will handle the rest, and the user will receive access automatically.</p>
